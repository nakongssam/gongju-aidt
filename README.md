# 공주시 AIDT (2026 공주시 교육발전특구 · 일반고 과학·수학)

바로가기: index.html (GitHub Pages 주소의 첫 화면)


## 학생
1. `index.html`을 열고 차시를 선택합니다. 처음 열면 학번·이름을 입력합니다.
2. 수업 중 선생님 안내에 따라 왼쪽 메뉴 맨 위 **🎬 이 차시 영상 모음**에서 영상을 봅니다. 파일로 열면 유튜브 새 탭에서 재생됩니다.
3. 답변·퀴즈·자기진단은 입력하는 즉시 자동 저장됩니다. 창을 닫았다가 다시 열어도 이어서 할 수 있습니다.
4. 퀴즈는 기회가 2번 있습니다. 틀리면 힌트와 '관련 개념 다시 보기' 링크가 나옵니다.
5. 마지막 페이지 **📊 나의 학습 리포트**에서 결과를 확인하고 **📤 선생님께 제출하기**를 누릅니다. 제출 설정이 안 되어 있으면 **📥 학습 기록 내려받기**로 받은 파일을 제출합니다.

## 교사 모드
첫 화면이나 차시의 학습자 정보 창에서 **👩‍🏫 교사 모드로 보기**를 누르면 학번·이름 없이 볼 수 있습니다. 교사 모드에서는 제출 기록이 남지 않고, 퀴즈 정답·해설 표시를 왼쪽 아래에서 켜고 끌 수 있습니다. 주소 끝에 `?mode=teacher`를 붙여도 교사 모드로 열립니다.

## 교사 — 구글 시트 제출 설정 (처음 한 번, 약 5분)
1. 구글 드라이브에서 새 구글 시트를 만듭니다. 이름 예시: `AIDT 제출함`
2. 시트 메뉴 **확장 프로그램 → Apps Script**를 엽니다. 기본 코드를 지우고 `apps-script.gs`의 내용을 전부 붙여넣습니다.
3. 코드 위쪽 `TEACHER_KEY`의 값을 선생님만 아는 비밀번호로 바꾸고 저장(💾)합니다.
4. **배포 → 새 배포** → 톱니바퀴에서 **웹 앱** 선택
   - 실행 사용자: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
   - **배포** → 권한 승인(고급 → '…(으)로 이동' → 허용)
5. 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사합니다.
6. AIDT 폴더의 `aidt-config.js`를 메모장으로 열고, `submitUrl: ''`의 따옴표 안에 URL을 붙여넣어 저장합니다.
7. 아무 차시나 열고 리포트에서 **선생님께 제출하기**를 눌러 보세요. 시트에 `제출기록`과 `서술형응답` 탭이 생기면 설정이 끝난 것입니다.

설정을 마친 AIDT 폴더를 학생에게 배포하면 됩니다(이미 나눠 준 경우에는 `aidt-config.js` 파일만 바꿔 주면 됩니다).

### 시트 구성
- **제출기록**: 학생·차시당 1행입니다. 진행률, 성취도, 수준, 자기진단, 학습 시간, 영상 시청, 문항별 결과(O/△/X)가 들어갑니다. 학생이 다시 제출하면 같은 행이 최신 기록으로 바뀝니다.
- **서술형응답**: 학생이 작성한 답변이 질문별로 한 줄씩 들어갑니다.
- **제출 마감**: 시트에 `제출마감`이라는 이름의 탭을 추가하면 제출이 막히고, 탭을 지우면 다시 열립니다.

### 대시보드에서 보기
`teacher.html`(교사용 대시보드) → **구글 시트에서 불러오기**에 웹 앱 주소와 비밀번호를 넣고 **불러오기**를 누릅니다. 문항 정답률, 보충이 필요한 학생, 서술형 응답 모아보기, CSV 내려받기를 쓸 수 있습니다. 학생이 파일로 낸 기록은 위쪽 상자에 끌어다 놓으면 함께 분석됩니다.

### 문제 해결
- **'모든 사용자'를 고를 수 없는 경우**: 학교 구글 계정은 관리자 정책으로 막혀 있을 수 있습니다. 개인 Gmail 계정으로 시트와 스크립트를 만드세요.
- **스크립트 코드를 고친 경우**: **배포 → 배포 관리 → 편집(연필) → 버전: 새 버전 → 배포**를 해야 반영됩니다. 이렇게 하면 URL은 그대로 유지됩니다.
- **제출이 안 되는 경우**: 인터넷 연결을 확인하세요. 학생은 학습 기록 파일을 내려받아 대신 제출할 수 있습니다.

## 참고
- 학습 기록은 학생 기기의 브라우저에 저장됩니다. 같은 기기를 여러 학생이 쓸 때는 리포트의 '처음부터 다시 하기'로 기록을 지운 뒤 다음 학생이 사용하세요(학습자 정보는 차시 왼쪽 아래 '수정'에서 바꿉니다).
- 성취도는 1차 정답 1점, 2차 정답 0.5점으로 계산합니다. 80점 이상은 상, 50점 이상은 중, 50점 미만은 하입니다. 퀴즈를 다 풀지 않았으면 '미완료'로 표시됩니다.
- 제출하면 학생 이름, 학번, 답변이 선생님의 구글 시트에 저장됩니다. 학생에게 미리 안내해 주세요.
- 폴더 구조(`index.html`, `aidt-config.js`, `science/`, `math/`)를 유지해야 링크와 제출 기능이 작동합니다.
